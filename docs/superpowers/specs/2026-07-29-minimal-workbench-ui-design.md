# 极简 HTML 转 Figma 工作台设计

## 目标

把当前密集的开发调试页面改为清晰、低负担的极简工具工作台，让产品人员快速选择自动识别或直接手动抓取。

## 布局

- 页面中心是一张最大宽度 1120px 的工作台卡片；顶部仅保留产品名称和一句用途说明。
- 左侧为上传区域，上传后替换为入口 HTML、文件数与“重新选择”摘要。
- 右侧为操作区域：先显示“自动识别”“直接手动抓取”两个并列主操作；随后按模式和状态显示补录操作。
- 宽、高、等待、自动状态上限、Figma 页面名放入默认折叠的“高级设置”。
- 底部状态条统一显示进度、成功、错误、状态数量和 Figma 导入地址。

## 交互

- 未上传时两个模式按钮禁用，上传后启用。
- 自动识别运行时仅显示进度，避免重复点击；完成后显示“开始补录”。
- 直接手动抓取运行时显示“正在保存首页并打开补录窗口”；进入补录后显示“抓取当前页面”“结束补录”。
- 不再展示长文件列表；只显示文件总数和优先 HTML，用户可展开查看前 8 个文件。

## 视觉

- 使用浅灰蓝背景、白色工作台、深蓝文字与青绿色主操作色。
- 采用 12px 圆角、柔和阴影和充足留白；按钮高度 44px。
- 自动识别为实心主按钮，直接手动抓取为边框强调按钮；破坏性错误只在状态条使用浅红色。

## 验收

1. 上传前页面不出现无效的补录控制。
2. 上传后用户可以一眼看到两种模式及其差异。
3. 常用操作不需要修改高级设置即可完成。
4. 原有上传、自动识别、直接手动抓取、补录和 Figma session 地址功能都保留。
