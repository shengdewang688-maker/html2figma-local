# HTML/CSS 转可编辑 Figma 使用说明

这份文档给第一次使用的人看。照着做就行。

目标是：给一个本地 HTML 文件和 CSS 文件，把页面导入到 Figma，生成一组可以编辑的 Figma 图层。

## 先回答最重要的问题

### 1. 要不要把整个工具文件夹发给新电脑？

要发。

建议把整个 `html转可编辑figma工作流` 文件夹打包发过去，但不要带这些东西：

- `node_modules/`
- `.html2figma*/`
- `dist/`
- `.git/`
- `.DS_Store`

这些可以在新电脑重新生成。

### 2. HTML 和 CSS 怎么发？

把 HTML/XHTML、CSS、JS、图片、字体、媒体、WASM 等资源按原来的目录结构一起发。

例如原来是这样：

```text
活动管理demo/
  index.html
  styles.css
  images/
  fonts/
```

就把整个 `活动管理demo` 文件夹一起发，不要只发 `index.html`。

因为入口文件通常会这样引用 CSS、图片或模块：

```html
<link rel="stylesheet" href="./styles.css">
<img src="./images/a.png">
```

目录结构变了，页面就可能打不开或样式丢失。

如果项目是 React、Vue、Angular、Svelte、Astro、Next.js 或 Nuxt：不要上传 `.tsx`、`.vue`、`.svelte` 等源码来直接抓取。先执行项目原本的构建/静态导出命令，再上传生成的 `dist/`、`build/`、`out/`、`public/`、`wwwroot/`、`.output/public/` 或 `.vercel/output/static/` 目录。工具支持这些目录，并会优先识别其中的 `index.html`、`index.xhtml` 等入口。

## 新电脑需要准备什么

新电脑需要安装：

1. Node.js，建议 20 或以上。
2. Figma 桌面版，或者能运行开发插件的 Figma。
3. 能编辑目标 Figma 文件的账号权限。

检查 Node 是否安装成功：

```bash
node -v
npm -v
```

能看到版本号就可以。

## 第一步：把工具放到新电脑

把压缩包解压到一个固定位置，例如：

```text
/Users/你的用户名/Documents/html转可编辑figma工作流
```

然后打开终端，进入这个工具目录：

```bash
cd "/Users/你的用户名/Documents/html转可编辑figma工作流"
```

安装依赖：

```bash
npm install
```

如果后面提示浏览器缺失，再运行：

```bash
npx playwright install chromium
```

不熟悉命令行的话，也可以直接双击启动文件：

- macOS：`scripts/start-html2figma-mac.command`
- Windows：`scripts/start-html2figma-windows.bat`

第一次双击时会自动安装依赖和 Playwright Chromium，时间会稍微久一点。

## 第二步：准备 HTML/CSS 文件

假设你的页面文件在这里：

```text
/Users/你的用户名/Desktop/活动管理demo/index.html
```

CSS 文件在同一个文件夹里：

```text
/Users/你的用户名/Desktop/活动管理demo/styles.css
```

确认浏览器能打开这个 HTML 文件，并且样式正常。

如果浏览器打开都乱了，导入 Figma 也会乱。

## 第三步：最简单方式，打开拖拽工具

在工具目录里运行：

```bash
npm run app
```

或者双击启动文件：

- macOS：`scripts/start-html2figma-mac.command`
- Windows：`scripts/start-html2figma-windows.bat`

运行后会自动打开一个本地网页。如果没有自动打开，就复制终端里的地址到浏览器，例如：

```text
http://127.0.0.1:4888
```

然后：

1. 把包含可运行入口、CSS、JS、图片、字体的整个项目或静态导出文件夹拖进去。
2. 确认“优先 HTML”选中的是 `index.html`、`index.xhtml` 或你最想排在前面的页面。
3. 点击“生成所有 HTML 给 Figma 插件使用”。
4. 等状态变成 Ready 后，去 Figma 运行插件并点击 `Import latest session`。

工具会自动发现文件夹里的 `.html`、`.htm`、`.xhtml`、`.xht`、`.shtml` 和 `.shtm` 页面，并把它们放到同一个 Figma bundle 里。CSS、图片、字体、JS 模块、Web Manifest、WASM 和媒体资源要跟入口页面一起拖进来，保持原来的目录结构。

这个方式 macOS 和 Windows 都可以用。Windows 上也一样要拖整个文件夹，避免 CSS、图片相对路径丢失。

推荐使用 Chrome 或 Edge 打开这个本地网页，拖文件夹和选择文件夹最稳定。

## 命令行高级方式：创建配置文件

在工具目录里新建一个配置文件，例如：

```text
configs/my-page.config.ts
```

最简单配置如下：

```ts
import type { Html2FigmaConfig } from "../src/types.js";

export default {
  input: "/Users/你的用户名/Desktop/活动管理demo/index.html",
  viewport: { width: 1440, height: 900 },
  states: [
    { id: "home", url: "/", waitFor: 300 },
  ],
  discovery: {
    include: ["button", "a", "[role=button]", "[data-figma-capture]"],
    exclude: ["[data-no-capture]", "a[target=_blank]"],
    maxDepth: 100,
    maxAutoStates: 1000,
    maxCandidatesPerState: 200,
    maxModalActionsPerPath: 2,
    maxPageActionsPerPath: 2,
    inventoryExtraStates: 3,
    maxEmptyExpansions: 12,
    skipTextPatterns: ["^查询$", "^重置$", "^刷新$", "^导出$", "^保存$", "^取消$", "^[‹›<>]$", "^\\d+$"],
  },
  output: {
    mode: "new-version-page",
    pageName: "HTML Import {{timestamp}}",
  },
} satisfies Html2FigmaConfig;
```

只需要先改一处：

```ts
input: "/Users/你的用户名/Desktop/活动管理demo/index.html",
```

改成你自己的 HTML 文件路径。

## 如果有弹窗、菜单、多个页面，要写 states

如果页面只有一个界面，用上面的 `home` 就够了。

如果页面里有弹窗、侧边菜单、不同页面，需要告诉工具怎么点出来。

例子：

```ts
states: [
  { id: "home", url: "/", waitFor: 300 },
  { id: "login-modal", from: "home", click: "[data-testid=open-login]", waitFor: 300 },
  { id: "activity-page", from: "home", click: '[data-page="activity"]', waitFor: 300 },
  { id: "activity-add-modal", from: "activity-page", click: "#activity-add", waitFor: 300 },
],
```

每一行的意思：

- `id`：导入到 Figma 后的名字，自己取。
- `url`：第一次打开页面，一般写 `/`。
- `from`：从哪个状态开始操作。
- `click`：要点击哪个按钮或链接。
- `waitFor`：点击后等多久，单位毫秒。

`click` 里面写的是 CSS selector。简单理解：

- `#activity-add` 表示点击 `id="activity-add"` 的元素。
- `.open-modal` 表示点击 `class="open-modal"` 的元素。
- `[data-page="activity"]` 表示点击有这个属性的元素。

不知道 selector 怎么写时，可以先让懂前端的人帮你标一下，或者在 HTML 里给按钮加一个好认的属性：

```html
<button data-figma-capture="open-login">登录</button>
```

然后配置里写：

```ts
click: '[data-figma-capture="open-login"]'
```

## 运行转换

回到工具目录，运行：

```bash
npm run dev -- convert --config configs/my-page.config.ts --out .html2figma-current
```

运行后终端会输出类似：

```text
Captured 14 state(s), 0 asset(s).
Bundle: .html2figma-current/bundle.json
Report: .html2figma-current/report.json

Companion session server: http://127.0.0.1:4777/session/latest
Open Figma, run the local companion plugin from plugin/manifest.json, then click Import latest session.
Press Ctrl+C here after the Figma import finishes.
```

重要：这个终端窗口不要关。

它要一直开着，Figma 插件才能读取转换结果。

## 在 Figma 里加载插件

打开 Figma 目标文件。

然后执行：

```text
插件 > 开发 > Import plugin from manifest...
```

选择这个文件：

```text
html转可编辑figma工作流/plugin/manifest.json
```

导入成功后，运行：

```text
插件 > 开发 > HTML2Figma Local Companion
```

插件窗口里会看到：

```text
http://localhost:4777/session/latest
```

点击：

```text
Import latest session
```

等它导入完成。

导入完成后，Figma 里会出现一个新页面，例如：

```text
HTML Import 2026-07-02 10-30
```

每次重新导入都会创建一个新页面，不会覆盖旧页面。

## 第七步：导入完成后关闭服务

Figma 导入完成后，回到终端，按：

```text
Ctrl + C
```

这样本地服务就关掉了。

## 以后页面改了怎么办

HTML/CSS 改完后，重新运行：

```bash
npm run app
```

重新拖入项目文件夹并生成。然后在 Figma 里重新运行插件，再点：

```text
Import latest session
```

它会生成一个新的 Figma 页面。

## 常见错误

### Failed to fetch

意思是 Figma 插件读不到本地服务。

检查：

1. 终端里的转换命令还开着吗？
2. 插件里地址是不是：

```text
http://localhost:4777/session/latest
```

3. 浏览器打开这个地址是否能看到一大段 JSON：

```text
http://localhost:4777/session/latest
```

如果打不开，重新运行转换命令。

### Manifest error: allowedDomains

不要把插件地址改成 `127.0.0.1`。

Figma manifest 里必须使用：

```text
http://localhost:4777
```

插件输入框也建议使用：

```text
http://localhost:4777/session/latest
```

### 端口不是 4777

插件默认只允许访问 `4777`。

如果 `npm run app` 提示 `Port 4777 is already in use`，通常是因为旧服务没关。

先关掉旧服务，或者在终端按 `Ctrl + C`，再重新运行拖拽工具。

### 页面没有 CSS 样式

检查 HTML 里 CSS 路径是否正确。

如果 HTML 里是：

```html
<link rel="stylesheet" href="./styles.css">
```

那 `styles.css` 必须和 `index.html` 在同一个文件夹。

### 弹窗没有导入

需要在配置文件 `states` 里写点击动作。

比如：

```ts
{ id: "add-modal", from: "home", click: "#open-add-modal", waitFor: 300 }
```

### 字体或位置有点偏

这是 HTML 到 Figma 转换最常见的误差。

当前工具会尽量保留：

- 文本内容
- 字号
- 颜色
- 行高
- 对齐
- 不换行规则
- 图片层
- 表格和按钮位置

但不同电脑缺字体时，Figma 可能用替代字体，文字宽度会有轻微变化。

## 这个工具生成的 Figma 哪些是可编辑的

可以编辑：

- 文字
- 按钮
- 表格
- 背景色
- 边框
- 图片层
- SVG 图标
- 页面 Frame

不是完全可编辑的：

- canvas
- video
- 很复杂的 CSS filter
- 很复杂的混合模式或特效

这些会尽量作为图片层保留视觉效果。

## 一句话流程

```text
发工具文件夹和 HTML 项目文件夹
-> 新电脑 npm install
-> npm run app
-> 浏览器拖入 HTML 项目文件夹并生成
-> Figma 导入 manifest
-> 运行插件
-> Import latest session
-> 得到可编辑 Figma 页面
```
